# 🔊 Text to Speech Converter

Type any text, pick a voice, and hear it read aloud using the browser's built-in **Speech Synthesis API**.

## ✨ Features

- Text area for any input
- **Voice selector** with every voice available in your browser/OS
- **Listen** button to play the speech

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla, Web Speech API — `SpeechSynthesis`)
- [Font Awesome](https://fontawesome.com/)

## 📁 Project Structure

```
15 text to voice converter/
├── index.html
├── style.css
└── script.js
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/vyom1912/<repository-name>.git
   ```
2. Open `index.html` in your browser — no build step or installation needed.

> Tip: For the best experience, use the **Live Server** extension in VS Code.

> The available voices depend on your browser and operating system.
